# Quiz template

Create 5–8 questions using this lesson's real classes/methods/errors. Include at least one "what breaks if..." and one trick question.
Each answer: bold short label and 1–4 plain sentences; name the actual failure/output for breakage questions and explain the trick.

```markdown
# Check yourself

Try each answer before opening it.

1. <Question tied to the lesson>

   <details><summary>Answer</summary>

   **<Short answer>.** <Concrete explanation.>

   </details>
```

Keep answers directly below questions, the details block indented three spaces, and blank lines after summary/before closing details so Markdown renders.
